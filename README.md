# ЭХО — IndieHorrorVR

Хоррор для VR на **WebXR** (Three.js). Слепое существо «Слушатель» реагирует только на звук: тишина — твоё оружие, шум — риск.

> Это **вертикальный срез (v0.1)** по плану из [`docs/PLAN.md`](docs/PLAN.md): Акт I — кабинет → коридор → лаборатория → лифт.

## Запуск

Нужен любой статический сервер (сборка не требуется, Three.js подключается с CDN через import map).

```bash
npm start            # или: python3 -m http.server 8000
```

Открой `http://localhost:8000` — кнопка **«Играть на ПК»** запускает тестовый режим без шлема.

### Тест на Meta Quest
WebXR требует HTTPS или `localhost`. Два пути:

1. **GitHub Pages** (проще всего): Settings → Pages → Source: **GitHub Actions**. После пуша в `main` игра будет по адресу `https://aphextwinxp.github.io/IndieHorrorVR/` — открой его в браузере Quest и нажми **ENTER VR**.
2. **USB-отладка**: `adb reverse tcp:8000 tcp:8000`, затем в браузере Quest открой `http://localhost:8000`.

## Управление

| | VR (Quest) | ПК (тест) |
|---|---|---|
| Идти | левый стик (слегка = красться) | WASD (Shift — красться) |
| Поворот | правый стик (snap 30°) | мышь |
| Телепорт | клик левого стика → режим «телепорт», правый стик вперёд + отпустить | — |
| Присесть | присесть по-настоящему | Ctrl / C |
| Взять / бросить | хват (grip) | E / ЛКМ |
| Фонарик / использовать | курок | F |
| Приглушить рацию | кнопка X | — |

## Настройка баланса

- `src/config.js` — скорости, радиус слышимости, батарея, скорость существа
- `src/level.js` — геометрия, свет (интенсивности ламп подбирай под устройство), предметы, зоны укрытия

## Структура

```
index.html
src/
  main.js       — сцена, WebXR, главный цикл
  config.js     — параметры баланса
  player.js     — VR/ПК-управление, телепорт, шаги = шум
  interact.js   — хват, бросок, фонарик, магнитофон, щиток
  monster.js    — ИИ «Слушателя»
  nav.js        — навигационная сетка + A*
  noise.js      — система шума
  audio.js      — процедурный 3D-звук
  level.js      — уровень и предметы
  game.js       — сюжет, цели, смерть/рестарт, финал
  ui.js         — интерфейс на запястье, затемнение
  mic.js        — микрофон (опционально)
  physics.js    — коллизии
docs/PLAN.md    — исходный сценарий и план
```

## Заметки

- Версия Three.js закреплена: `0.160.0`.
- Микрофон спрашивается **до** входа в VR (в шлеме запрос разрешения может не показаться).
- Проект не тестировался на реальном шлеме при создании — первым делом проверь FPS и комфорт движения на Quest и скорректируй `config.js` / свет.
